# Greeting app

Before lesson 0, have your own verified GitHub account, Git 2.31+ and school-approved access/privacy. Read the [account and privacy setup](https://zero.codepet.ca/docs/setup#before-lesson-0-github-and-privacy). Choose Private unless teacher/school policy says otherwise, invite your teacher as a collaborator and verify access; collaborators can edit. Use a teacher-approved commit identity and the exact GitHub noreply email for email privacy. Publishing is optional/public; private-repository Pages depends on the plan. No paid plan is needed for tutorial source work.

Create your own GitHub repository from the published tutorial template, then clone YOUR repository with VS Code **Git: Clone**. Open that cloned folder in Zero. A ZIP or a folder inside another repository cannot start this tutorial.

Keep using your repository for lessons 0–2 as you write your own code. The scaffold contains only setup and an empty Main; the first run opens a blank window or canvas.

Open src/main/java/Main.java and read the [first lesson](https://zero.codepet.ca/tutorials/0). After edits, click **Run App again**. Run uses local Git checks and needs no GitHub sign-in. Sign in when you want to Upload, start a New branch, or Finish change. Submit your repository link separately in Pika.

ZeroHub contributions belong in a separate original project. Keep this tutorial repository for learning.
